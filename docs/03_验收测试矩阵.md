## 指标记录

测试报告必须写明：机器配置、文件数与总字节量、提取文本总量、索引大小、首次/增量索引时间、查询 P50/P95 延迟、OCR 每页耗时、进程峰值内存，以及每类格式的成功/失败/跳过数量。**无固定毫秒 SLA，但要记录和回归性能。**

## 待实机验证

本轮使用 M4 Windows x64 便携包。ZIP 的 SHA256 为 `d510b76f1f0d02500739339d0fad3b1ffb44dc6b87926ea3a595a0b8224a92b3`。请使用合成文件和独立数据库。M4 首次打开旧库会升到 v4，需要用旧版打开的数据库应事先留一份副本。 [下载便携包](https://github.com/mazhujie/IndexFox/releases/download/v0.1.0-m4/IndexFox-windows-x64-portable.zip)

| 待测项 | 操作 | 通过标准 |
|---|---|---|
| [ ] M4.8 干净 Windows 与系统断网（Q28、Q29） | 在无 Evergreen WebView2 的 Windows x64 测试机或虚拟机上，预先复制 ZIP 和合成样本，断开系统网络。用普通用户把包解压到本地目录，直接启动 `IndexFox.exe` 并添加样本目录。 | 无需安装运行时或提权。WebView2 进程来自解压目录的 `runtime\webview2`。扫描 PDF 可搜到 `内核驱动` 和 `VIDIOC_STREAMON`，命中标为 OCR，并能打开原页和文本高亮。容错模式搜索 `dma_alloc_cohernt` 能高亮原文 `dma_alloc_coherent`。 |
| [ ] 外部 NAS 实际断连（Q20） | 索引外部测试共享中的文件，确认能搜到正文，再断开共享并触发扫描。恢复共享后修改或删除一份合成文件，再完整扫描。 | 断连时来源标为离线，旧命中和缓存正文可读。恢复并完成扫描后，索引反映修改或删除。 |
| [ ] WSL 发行版实际停机（Q20） | 用独立测试发行版的 UNC 目录建立索引。停止该发行版并触发扫描，再启动发行版并完整扫描。 | 停机时来源标为离线且旧索引保留。重新启动后来源恢复并完成对账。 |
